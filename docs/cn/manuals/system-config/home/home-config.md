# 首页配置

<img src="/images/Setting/Configuration/home/1.png" alt="index" style="max-width:100%; height:auto;" />

首页配置用于自定义**Edge 前端首页看板**中各数据卡片的显示内容与计算方式。通过配置，可将系统中的通道点位、设备实例点位或自定义公式与页面固定位置的数据卡片关联，实现实时数据的展示。

**主要功能：**

- 配置首页所展示的数据点位
- 自定义点位显示名称、单位、图标
- 使用公式将 Channel 点位、Instance 点位、常数进行组合计算
- 配置可持久化保存，页面加载后自动应用
