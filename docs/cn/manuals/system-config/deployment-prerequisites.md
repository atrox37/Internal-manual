# 部署前提

在进行 EMS 系统部署之前，需要首先完成网关机的网络连接。根据现场环境，可采用以下两种方式之一与网关机建立连接。

**所需工具**：网线、网关机、电脑（或笔记本）

## 网络连接方式

无论采用哪种方式，网线均需接入网关机的 **LAN2** 口。LAN2 口位于网关机前面板左侧四个以太网口中的**左下角**，如图所示：

<img src="../../../images/Setting/Install/lan2-port.png" alt="网关机 LAN2 口位置示意" style="max-width:100%; height:auto;" />

网关机 LAN2 的默认 IP 地址为 **192.168.1.233**。

### 方式一：同一局域网连接

适用于电脑与网关机已接入同一路由器或交换机的场景（如现场部署、办公室调试）。

1. 将网线一端接入网关机的 **LAN2** 口，另一端接入路由器/交换机或电脑网口。
2. 确保电脑与网关机处于同一局域网内。

3. 在电脑上打开 EMS Edge Configuration 应用，使用网关机的 IP 地址进行连接（详情查看[登录页面](/cn/manuals/system-config/login.html)介绍）。

### 方式二：笔记本与网关机直连调试

适用于现场无路由器、需将笔记本与网关机**直接通过网线连接**进行调试的场景。

1. 将网线一端接入网关机的 **LAN2** 口，另一端接入笔记本网口。
2. 在笔记本上配置与网关机同网段的静态 IP（例如 192.168.1.100），子网掩码为 255.255.255.0。
3. 打开 EMS Edge Configuration 应用，使用上述 IP 地址（192.168.1.233）与网关机建立连接。

    >**注意:**
    > 1. **必须配置静态 IP**：直连模式下笔记本需**手动配置**与网关机同网段的静态 IP，**切勿使用自动获取（DHCP）**。直连时无 DHCP 服务器，自动获取将导致无法获取有效 IP，从而无法与网关机通信。
    >
    >       <img src="../../../images/Setting/Install/2.png" style="max-width:100%; height:auto;" />
    >
    >       1. 打开电脑上的**控制面板** → **网络和共享中心** → **更改适配器设置**，右击**以太网**。
    >       2. 点击**属性**按钮。
    >
    >       <img src="../../../images/Setting/Install/3.png" style="max-width:100%; height:auto;" />
    >
    >       3. 点击**Internet协议版本4（TCP/IPv4）**。
    >       4. 点击**属性** 按钮。
    >
    >       <img src="../../../images/Setting/Install/4.png"  style="max-width:100%; height:auto;" />
    >
    >       5. 进行如图所示的配置之后（IP地址可选其他），点击**确认**按钮。
    >
    > 2. **IP 地址冲突**：若笔记本已通过 WiFi 连接其他网络，请确认所配置的静态 IP（如 192.168.1.100）不与现有网络冲突；必要时可暂时禁用 WiFi，仅使用有线连接进行调试。
    > 3. **连接前检查**：确认网线两端已插紧，网口指示灯正常后再进行连接。
