# 部署前提

在进行EMS系统部署之前，需要首先对网关机的网络进行连接。

所需工具：网线、网关机、电脑

步骤：

1. 将网线接入到网关机的LAN2口，如图所示。

   <img src="../../../images/Setting/Install/1.png" alt="index" style="max-width:100%; height:auto;" />

2. 在同一局域网下，在电脑中使用EMS Edge Configuration应用与网关机进行连接（详情查看[登录页面](/cn/manuals/system-config/login.html)介绍） 。
