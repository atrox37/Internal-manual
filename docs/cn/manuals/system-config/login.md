# 登录功能

登录界面是您进入系统的第一步。系统提供了简洁美观的登录界面，包含用户名、密码输入框、IP地址输入框和登录按钮。

<img src="../../../images/Setting/Login/1.png" alt="登录界面" style="max-width:100%; height:auto;" />

1. 填写用户的基本信息：
   * `Username`：用户名
   * `Password`：用户密码
   * `Ip Address`：所要连接的网关机的IP地址，后续所有的数据交互都与该网关机进行
2. 点击**Login**按钮，进行登录。
